# Pearlz Home Systems — Product Firmware Changelog & Release Notes
Document ID: REL-FW-2025
Applicable Hardware: AquaPearl 500 Pro Smart Mainboard

## Firmware Version 2.4.1 (Released: September 20, 2025)
- Improved WiFi reconnectivity backoff logic after router restarts.
- Optimized sleep mode display dimming on ambient light sensor readings.

## Firmware Version 2.4.0 (Released: June 15, 2025) - CRITICAL UPDATE
- **Alert Code Realignment**: Alert code E-03 was redefined from 'General System Low Pressure' to specifically indicate 'Sediment Pre-filter Cartridge Saturation'. Low feed water pressure was reassigned to code E-01.
- Updated buzzer frequency from continuous tone to 3 short audible beeps for pre-filter alerts.
- Added self-healing recovery timer for pump overheat protection (E-02).

## Firmware Version 2.2.0 (Released: January 10, 2025)
- Initial public release of smart IoT firmware supporting Pearlz Android and iOS mobile applications.
- Integrated automated TDS calibration table for Northern Pakistan high-carbonate feed water.
